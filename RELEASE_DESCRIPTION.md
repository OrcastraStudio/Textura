# Draft release description — Textura 0.1.2 MIT source edition

Textura supports author-led multilingual research and writing through a local record system and AI-guided operating protocols for essays, poetry, fiction and game reviews. The source is shared to help readers understand the tools available during the creative process.

This candidate includes 20 core components for topics, sources, reading, evidence, drafts, review, style and fiction. It preserves source/version provenance and author choice. The optional Bibliotheca connector is disabled by default.

The Git preparation includes contribution and reporting documents, issue/PR templates, release guidance, hash-preserving Git attributes and history-directory placeholders. Revision 2 adds the MIT License with OrcastraStudio attribution, reader-facing guidance and public snapshots preceding the configuration/governance changes. It does not change the 0.1.2 executable workflow.

Style and long-fiction assistance remain agent-executed protocols and blank templates. No automatic model calls, publishing service, fiction-state engine or style-statistics engine are claimed.

Validation details and skipped coverage are documented in VALIDATION.md and GIT_VALIDATION.md. Personal records, source libraries and original private histories are excluded.

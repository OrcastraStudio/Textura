## Reading-boundary handoff

- For a first reader: only the manuscript prefix reached so far, neutral reading instructions and the selected perspective.
- Exclude every author-intent note, planning record, setting record and previous reader/editor interpretation, including material about already-read scenes.
- Exclude revealing filenames, titles, links and coordinator metadata.
- For a full editor: explicitly select applicable full-context records.

# Translation and cross-language understanding

Owns translation notes and terminology records under `current/records/`. It consumes original source and reading references and produces attributed, revisable interpretations. Source originals remain in Sources; claim support remains in Evidence.

This is an agent-executed protocol, not an installed machine-translation service. All source languages are eligible, but reliable processing is not guaranteed for every language or historical form. Read [protocol.md](protocol.md) and use [translation-note.template.md](translation-note.template.md).

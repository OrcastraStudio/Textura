# Data analysis

Owns requested analysis plans, reproducible transformations, outputs and interpretation notes within this component's `current/records/`. Source datasets remain registered in Sources; extracted data link to Reading; resulting claim assessments belong to Evidence.

Default work explains and checks existing research. A new analysis starts on the author's request. No statistical package, model or data feed is assumed installed. The operating AI uses available tools, records actual methods and separates computation from interpretation.

Read [protocol.md](protocol.md); use [analysis-plan.template.md](analysis-plan.template.md) before new analysis.

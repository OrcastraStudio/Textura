# Publication preparation

Owns prepared publication derivatives, excerpts, introductions and output manifests under `current/records/`. Writing remains authoritative for the full manuscript; Evidence owns source support and assessments.

The initial module prepares content and files for the author to publish. It has no automatic posting, account connection, comment sending or channel-monitoring capability. The author selects each intended medium; no platform account or fixed destination list is configured.

Read [protocol.md](protocol.md) and complete [publication-package.template.md](publication-package.template.md). Do not infer that every output format has an installed renderer.

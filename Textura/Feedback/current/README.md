# Selected reader feedback

Owns the author's selected comments, context and feedback analyses under `current/records/`. Comments can suggest new questions, evidence or revisions; source registration and claim assessment remain with Sources and Evidence.

The author supplies or selects feedback. Initial Textura does not collect all platform comments, monitor accounts or send replies. Read [protocol.md](protocol.md) and use [feedback-note.template.md](feedback-note.template.md).

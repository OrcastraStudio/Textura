# Evidence

`original_inspected` is unknown (`null`) unless an assessor explicitly supplies a boolean. It concerns the attributed original, including an upstream work mentioned by a secondary source; successful excerpt matching never sets it to true. Each accepted reference also stores the acquired source digest and exact Reading record digest. Revisions to extraction require a new reading and a new assessment, preserving earlier anchors.

This is the single authoritative ledger for claims and assessments. `evidence.py` separates factual, quotation, numeric, causal, interpretive, speculative and value statements. Critical claims, direct quotations, numbers and causal inferences receive priority; unchecked claims remain visibly unassessed.

Assessment submission requires a rationale; decisive verdicts require excerpts at actual saved reading locators. The local tool checks IDs, source hashes and excerpt presence. It does **not** verify the truth of a claim, the authority of a source, or logical entailment. A technically accepted `supported` entry remains the named assessor's judgment and is available for substantive review.

Agents must check attribution, quote fidelity, context, counterevidence and the inference being made. A valid DOI or real page is not proof that it supports the manuscript. Keep originating sources and reposts distinct. When only a secondary source was read, record the source actually inspected and the missing upstream original in `attribution_chain`; never disguise a secondary quotation as firsthand consultation. Translation records link back to originals and preserve uncertainty.

Claims attach to a work's active draft when one exists. Later changes get a new claim and optional `supersedes` link; assessments are append-only. A changed draft or source requires substantive re-checking. Review consumes this ledger; it must not keep a competing global truth status.

Records live under `current/records/claims` and `current/records/assessments`. Evidence input JSON for `assess --evidence-file` is an array: `[{"reading_id":"reading-ID","locator":"ACTUAL_LOCATOR","excerpt":"Exact source text","attribution_chain":[]}]`.

Exploratory inclusion is an editorial choice, not an evidentiary verdict. Under the configurable starter editorial policy, a hypothesis or interpretation may remain in the body with supporting evidence, relevant counterexamples and gaps visible. Preserve its kind and unresolved assessment where appropriate; repetition, fluent phrasing or author inclusion never converts it into an established premise. An objection generated by AI is a hypothetical analytical objection unless an actual external source supports its attribution.

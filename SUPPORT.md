# Support and capability boundaries

Start with [README](README.md), [commands](Textura/Runner/current/COMMAND.md) and [known release decisions](PENDING_DECISIONS.md).

For reproducible defects, use the bug template and include version, Python/OS, exact command and a minimal synthetic example. For design discussion, use the feature template or the host's discussion feature if enabled. No external support address or guaranteed response time is configured.

Textura is a local record system plus AI-executed protocols. It does not bundle an AI subscription, web search service, graphical editor, automatic fiction engine or automatic publication service. All source languages are eligible; support for a specific file format is a separate reader capability. Style and fiction templates do not execute analysis themselves.
